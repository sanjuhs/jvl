Interactive editor

Write JVL. Run it here.

The whole compiler runs in your browser — no server, no wait. Edit the program, hit a command, and read the trace. Pick a lesson to learn a concept, or describe a scenario in plain English and let the AI draft the JVL.

$ jvl run

✨ AI helper — draft JVL from plain English

The helper needs an ANTHROPIC_API_KEY set on the deployment. Without it, it hands you a ready-made prompt to paste into any LLM.

This editor runs a JavaScript port of the reference compiler (a faithful subset). For the full toolchain — diff, equiv, emit, simulate — use the Python CLI.

JVL is a research prototype. It is not a lawyer, does not give legal advice, and its output must be reviewed by a qualified human before it informs any real decision.
